# Issue Documentation

This directory contains documentation for significant GitHub issues and their implementations.

## Structure

Each issue gets a markdown file: `<issue-number>-<brief-description>.md`

Example: `606-ollama-local-models.md`

## Template

```markdown
# Issue #XXX: Title

**Status:** In Progress | Completed | Blocked
**PR:** [#YYY](link)
**Branch:** `issue/XXX-description`

## Summary
Brief description of what this issue addresses.

## Changes
### New Files
- `path/to/file.py` - Description

### Modified Files
- `path/to/file.py` - What changed

## Testing
How to test the changes.

## Notes
Any additional context, decisions made, or lessons learned.
```
