# Issue #441: Failed Extractions Handling - Implementation Plan

## Problem Statement
When content extraction fails (404, redirect loops, timeouts), analyses are incorrectly marked as "completed" with error page titles like "Not Found - Claude Docs".

## Root Cause Analysis

### Current Flow (Broken)
1. JinaReader extracts content, including title
2. Title is stored BEFORE error detection
3. All errors become generic "EXTRACTION_FAILED"
4. No abort signal - workflow continues
5. Analysis marked "complete" with error page title

### Key Gaps
- No `_is_error_page()` detection
- No error categorization (404 vs 500 vs timeout)
- No `error_code`/`error_message` fields in database
- No abort signal in workflow state
- No conditional abort edge in LangGraph

---

## Implementation Phases

### Phase 1: Error Page Detection in JinaReader
**File:** `app/shared/services/extraction/jina_reader.py`

**Tasks:**
- [1.1] Add `_is_error_page(title, content) -> bool`
  - Check title for: "404", "not found", "redirecting", "access denied"
  - Check content for error indicators
- [1.2] Add `ExtractionErrorCode` enum in `app/core/exceptions.py`
  - HTTP_404, HTTP_5XX, TIMEOUT, ERROR_PAGE, REDIRECT_LOOP
- [1.3] Enhance `JinaReaderError` with `error_code` field

**Dependencies:** None (foundation layer)

### Phase 4: Extract Content Task - Error Handling
**File:** `app/domains/analysis/workflows/tasks/extract_content.py`

**Tasks:**
- [4.1] Call `_is_error_page()` AFTER extraction, BEFORE storing title
- [4.2] On error, return state with:
  ```python

      "should_abort": True,
      "abort_reason": f"Error page detected: {title}",
      "extraction_status": "failed",
  }
  ```
- [4.3] Don't re-raise exception - let graph handle abort
- [4.4] Update repository with error fields via `mark_failed()`

**Dependencies:** Phase 1, 2, 3

---

### Phase 5: Graph Builder - Conditional Abort Edge
**File:** `app/domains/analysis/workflows/graph_builder.py`

**Tasks:**
- [5.1] Add routing function:
  ```python
  def _route_after_extraction(state: AnalysisState) -> str:
      if state.get("should_abort"):
          return "workflow_failed"
      return "continue"
  ```
- [5.2] Add "workflow_failed" node that emits SSE error event
- [5.3] Replace extract → embedding edge with conditional edges:
  ```python
  graph.add_conditional_edges(
      "extract",
      _route_after_extraction,
      {"continue": "embedding", "workflow_failed": END}
  )
  ```

**Dependencies:** Phase 3, 4

---

### Phase 6: Repository - mark_failed() Method
**File:** `app/db/repositories/analysis_repository.py`

**Tasks:**
- [6.1] Add method:
  ```python
  async def mark_failed(
      self,
      analysis_id: UUID,
      error_code: str,
      error_message: str,
      failed_at_stage: str = "extraction"
  ) -> None:
      await self.session.execute(
          update(Analysis)
          .where(Analysis.id == analysis_id)
          .values(
              status="failed",
              error_code=error_code,
              error_message=error_message,
              failed_at_stage=failed_at_stage
          )
      )
      await self.session.commit()
  ```

**Dependencies:** Phase 2
