---
Follow SkillForge ADR template:

1. Ask for context and problem statement
2. Ask for decision and alternatives considered
3. Ask for consequences and trade-offs
4. Generate ADR markdown document with timestamp

Save to: docs/adr/YYYY-MM-DD-{title}.md

Template sections:
- Status: Proposed/Accepted/Rejected/Deprecated
- Context: Problem statement
- Decision: What was chosen
- Consequences: Positive and negative impacts
- Alternatives: Options that were considered
