---
description: LLM security patterns
---
Implement security patterns for LLM applications:

1. **Context Separation**: Separate system prompts from user data
2. **Input Validation**: Zod schema validation for all inputs
3. **Output Sanitation**: Sanitize LLM outputs before storage
4. **Rate Limiting**: Protect against abuse
5. **Prompt Injection Prevention**: Detect and block malicious prompts

Follow SkillForge llm-safety-patterns.
