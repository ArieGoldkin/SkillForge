Build design system from tokens:

1. Ask for:
   - Design tokens (colors, spacing, typography)
   - Component variants
   - Accessibility requirements

2. Generate:
   - TailwindCSS with custom config
   - Component library structure
   - Type-safe props using Zod
   - ARIA labels and roles

3. Place in: frontend/src/components/ui/

Follows SkillForge design-system-starter patterns.
