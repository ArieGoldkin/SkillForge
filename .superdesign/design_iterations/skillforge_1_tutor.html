How do Server Components differ from Client Components?

Great question! Let me guide you to discover this yourself.

First, think about where traditional React components execute. Do they run on the server or in the browser?

And what challenges might arise from that execution environment when it comes to:

  • Data fetching
  • Bundle size
  • Access to server-only resources (databases, file systems)

Traditional React runs in the browser, so we can't access databases directly and have to make API calls for data.

Exactly! You've identified a key limitation. Now, what if we could run some components on the server instead?

Consider this example:

// Server Component (runs on server)
async function ProductList() {
const products = await db.query('SELECT * FROM products')
return <div>{products.map(p => ...)}</div>
}
